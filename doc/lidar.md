# Lidar

## Hardware

For this project, I used the **RPLIDAR A1M8** from Slamtec. It is a low-cost, 360-degree 2D LiDAR sensor, capable of performing 2D SLAM and object detection within a range of up to 12 meters. It uses a rotating laser to perform 360° scans of the environment, making it ideal for small robotics projects and indoor mapping.

## SDK

I used the **official SDK provided by Slamtec**, which is written in C++ and provides APIs for interfacing directly with the LiDAR hardware.

> **Note:** The SDK is cross-platform and easy to build on Linux, including Raspberry Pi OS.

---

## Standalone Lidar Examples

To test and visualize the LiDAR data **outside ROS2**, I wrote two C++ examples using the official SDK:

### [display](../examples/lidar/exampleDisplay.cpp)

- Uses **OpenGL** to render a real-time 2D visualization of the point cloud generated by the LiDAR.
- Each scan produces a set of distance and angle measurements.
- Useful for checking the LiDAR’s functionality and real-world scan output before integrating into ROS2.

### [lidar](../examples/lidar/exampleLidar.cpp)

- Reads raw data from the A1M8 using the SDK and prints out scan data to the terminal.
- Simple and lightweight — ideal for debugging and verifying that the device is connected and streaming data correctly.

## ROS2 Integration

For ROS2 support, I used the **official ROS2 driver node provided by Slamtec**. This package wraps the SDK and publishes LiDAR data in ROS2 using standard message types.

### Features of the Node:

- Publishes data to the `/scan` topic using the `sensor_msgs/msg/LaserScan` message.
- Supports parameters for scan rate, angle filtering, and serial port configuration.
- Compatible with visualization and mapping tools like RViz, Nav2, and SLAM packages.
