# Sensor fusion
## The aim of the project is to fuse data acquired from 2 or more cameras and a lidar, resulting in a 2D map.

## Software requirements
### Everything is incapsulated in Docker containers that run on the ARM architecture. Each container contains a ROS2 node.

## Hardware used
### The project has been developed on a Raspberry Pi 5 (16GB) using 2 PiCameras: v2.1 and camera module 3 Wide and a A1M8 RPLidar.
